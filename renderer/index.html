    Settings

    ClearMail couldn't unlock some of your saved passwords, sign-ins or your Claude key from the macOS Keychain. Quit and reopen ClearMail and choose Always Allow when asked. Or enter them again: the accounts that need it are marked below.

    Accounts

      Finish signing in in your browser…

      A Microsoft sign-in page has opened in your web browser. Choose your account and accept. When the page says you're signed in, come back here.

      One-time setup for Outlook

      To open Outlook and Microsoft 365 mailboxes, ClearMail needs a free app ID from Microsoft. This copy of ClearMail doesn't have one built in, so it has to be added once.

      See "Using Outlook" in the README for the 5-minute setup.

      General

      Without a key, ClearMail still removes waffle offline. With a key, every email gets a plain-English one-liner, a to-do list and suggested replies.

      ClearMail was started with --demo, so it shows sample emails until you restart it normally.

      Advanced

      Add an email account

      SSL/TLS usually uses ports 993 and 465. STARTTLS usually uses 143 and 587.

      Use an app password, not your normal password. Gmail: myaccount.google.com/apppasswords · iCloud: account.apple.com → Sign-In and Security → App-Specific Passwords · Yahoo: Account Security → Generate app password. Changing the provider, address or server clears the saved password, so type it again.

      Outlook, Hotmail and Microsoft 365 (work or university) addresses can't use an app password. Go back and choose Add Outlook or Microsoft 365 instead.
